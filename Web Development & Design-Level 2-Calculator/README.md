# 🧮 Calculator Web Application (Oasis Infobyte Internship)

A sleek, responsive, and fully functional browser-based calculator built as part of the **Oasis Infobyte Web Development & Designing Internship (Level 2)**.


---

## 🛠️ Tech Stack Used
* **HTML5:** Structuring the calculator layout and buttons grid.
* **CSS3 & Bootstrap 5:** Styling the user interface, custom gradients, glassmorphism effects, and ensuring fully responsive design across all screen sizes.
* **Vanilla JavaScript (ES6+):** Implementing calculator logic, arithmetic operations, event handling, input validation, and real-time display updates.
* **FontAwesome:** Icons for visual enhancement.

---

## ✨ Features & Functionality
* **Basic Arithmetic Operations:** Supports addition (+), subtraction (-), multiplication (×), division (÷), and percentage (%) calculations.
* **Interactive Display Screen:** Shows real-time inputs and calculated results clearly.
* **Clear (C):** Resets the entire calculator state and clears the display.
* **Delete (DEL):** Removes the last entered character (Backspace functionality).
* **Division-by-Zero Prevention:** Safely catches zero-division attempts and outputs an error message instead of crashing.
* **CSS Grid Layout:** Designed with a precise CSS Grid template for a clean and organized keypad layout.
* **Responsive Design:** Fully adaptable to mobile phones, tablets, and desktop screens.
