# Steve Jobs Tribute Page

A modern, responsive, and visually immersive **Tribute Page dedicated to Steve Jobs**, created as a front-end web development task. The project presents his life, career, major innovations, and lasting impact through a cinematic design, interactive navigation, timeline, and animated sections.

---

## 🛠️ Tech Stack Used

* **HTML5:** Structuring the tribute page, navigation, biography, timeline, innovations, quote, and footer sections.
* **CSS3:** Custom styling, gradients, glassmorphism effects, animations, responsive layouts, hover effects, and typography.
* **Bootstrap 5:** Responsive grid system, navigation, buttons, spacing, utilities, and layout components.
* **Vanilla JavaScript (ES6+):** Typing animation, scroll-based navigation highlighting, section reveal animations, and back-to-top functionality.
* **FontAwesome:** Icons for interface elements.
* **Google Fonts:** Redaction and Winky Rough for a distinctive visual style.

---

## ✨ Features & Functionality

* **Hero Section:** Introduces Steve Jobs with his lifetime dates and an animated tagline.
* **Typing Effect:** Displays the phrase `"The Man Who Changed the Way We See Technology"` with a dynamic typing animation.
* **Biography Section:** Presents an original summary of Steve Jobs' life, career, and influence.
* **Interactive Timeline:** Highlights important milestones from 1955 to 2011.
* **Iconic Innovations:** Showcases the Macintosh, iPod, iPhone, and iPad.
* **Beyond Apple:** Covers Steve Jobs' work with NeXT and Pixar.
* **Famous Quote:** Features the well-known quote `"Stay hungry. Stay foolish."`
* **Active Navigation:** Automatically highlights the navigation link for the section currently being viewed.
* **Scroll Reveal Animation:** Sections smoothly appear as the user scrolls through the page.
* **Back-to-Top Button:** Allows users to quickly return to the top of the page.
* **Glassmorphism UI:** Uses translucent cards, blur effects, borders, and shadows for a modern interface.
* **Responsive Design:** Adapts the layout for desktop, tablet, and mobile screen sizes.
* **Custom Background:** Uses a cinematic Steve Jobs themed background with layered gradients and overlays.

---

## 📚 Page Sections

1. **Home** – Steve Jobs introduction and animated tagline.
2. **About** – Biography and early life.
3. **Timeline** – Major events and achievements throughout his career.
4. **Innovations** – Macintosh, iPod, iPhone, and iPad.
5. **A Vision Beyond Apple** – NeXT and Pixar.
6. **Quotes** – Steve Jobs' famous quote.
7. **Footer** – Closing tribute statement.
